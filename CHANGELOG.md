## [1.0.0] - 2025-02-24

### Added
- Initial release of DevPact
- Multi-Agent collaborative development with Supervisor, Frontend, and Backend agents
- Real-time discussion between agents
- Automatic generation of development contract documents
- Task breakdown for frontend and backend development
- Support for multiple LLM providers:
  - Chinese LLMs: Zhipu GLM, Qwen, Doubao, Kimi, MiniMax, DeepSeek
  - International LLMs: OpenAI, Claude, Gemini
- Multi-language support (Chinese and English)
- Cross-platform support:
  - macOS (ARM64, x86-64)
  - Windows (x86, x86-64, ARM64)
  - Linux (x86, x86-64, ARM, ARM64)
- GitHub Actions CI/CD for automated multi-platform builds
- DMG installer for macOS
- ZIP packages for Windows
- TAR.GZ packages for Linux
